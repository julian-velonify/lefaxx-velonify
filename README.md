# Le Faxx Jeans – Startseiten-Prototyp

Pitch-Prototyp von [Velonify](https://velonify.de) für Le Faxx Jeans (Istanbul HQ · Fabrik Sivas).

- `index.html` – klickbare Startseite (DE / EN / TR), statisch, ohne Build-Schritt
- `fonts/` – selbst gehostete Schriften (Big Shoulders Display, Inter)
- `docs/Startseite - Wireframe-Konzept.md` – Konzept Sektion für Sektion
- `DESIGN.md` / `.impeccable/design.json` – Designsystem

## Lokal ansehen

```bash
python3 -m http.server 8080
```

Dann `http://localhost:8080/?lang=de` öffnen (`?lang=en`, `?lang=tr`).

## Hinweis

Logo und alle Bilder/Videos sind Platzhalter (Unsplash/Pexels, Quellen im Konzept). Fakten und die −50 %-Werte von Knot Washed® vor Veröffentlichung mit Le Faxx bestätigen.
